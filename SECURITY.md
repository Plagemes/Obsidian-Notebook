# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for a security problem. Report it privately with a [GitHub security advisory](https://github.com/Plagemes/Obsidian-Notebook/security/advisories/new) (repository, Security tab, Report a vulnerability).

Include the plugin and Obsidian versions, what you found and how to reproduce it. Never include private notes. You will get a reply as soon as the maintainer can, and credit in the release notes if you want it.

## Supported versions

Only the latest release is supported.

## Scope

Notebook is local-first: no account, no cloud, no telemetry. Relevant reports include code execution through a crafted notebook or PDF, data loss or corruption, and anything that makes the plugin send data off the device.
